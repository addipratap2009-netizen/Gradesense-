THE PROBLEM → THE FLOW

One photo in, a graded answer out.

Every stack of answer sheets follows the same four steps — GradeSense just does the slow parts for you.

1

Upload the answer sheet

A teacher photographs a student's handwritten response, along with the rubric or model answer for that question.

2

OCR reads the handwriting

The image is converted to text, including flagging any words the model isn't confident about.

3

Semantic grading against the rubric

Instead of matching exact words, the model checks whether each rubric concept was actually addressed — the way a human grader would.

4

Teacher reviews, then finalizes

The score and feedback are proposed, not final — the teacher can edit anything before it's recorded.

FEATURES

Built for the grading desk, not a lab demo.

Concept-level matching

Recognizes a correct answer even when it's phrased nothing like the model answer.

Per-question feedback

Every mark comes with a reason — what was covered, and what was missing.

Teacher override

Every score is editable before it's saved. The model proposes; the teacher decides.

Confidence flags

Unclear handwriting is flagged for manual review instead of silently guessed.

CSV export

Finalized scores export in one click for the gradebook.

Class-level insight

See which concepts the whole class struggled with, not just individual scores.
